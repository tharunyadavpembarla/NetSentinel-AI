# NetSentinel AI

An AI-Powered Network Intrusion Detection & Monitoring System built using Python, FastAPI, Scapy, SQLite, HTML, CSS, and JavaScript.

# Features

- Live packet capture using Scapy
- Real-time monitoring dashboard
- FastAPI REST API
- SQLite database
- Automatic protocol detection (TCP, UDP, ICMP)
- Live packet statistics
- Alert classification
- Attack type detection
- Auto-refresh dashboard

# Tech Stack

- Python
- FastAPI
- Scapy
- SQLAlchemy
- SQLite
- HTML
- CSS
- JavaScript
